# Nabendu Das — Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready for GitHub Pages hosting.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for a user site, name it `nabendudas.github.io`; otherwise any repository name works).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. For a project repository, the URL will be `https://<username>.github.io/<repository>/`.

## Customize
- Update the email, phone, social links, project links, and content in `index.html`.
- Replace the CSS colors and typography in `style.css` if desired.
- The CV content was used as the source for education, research experience, projects, publications, skills, and awards. No CV PDF is included in this package.
